<p><strong><span data-contrast="auto">Reglas del Sistema de Combate</span><span data-ccp-props="{&quot;335559685&quot;:2124,&quot;335559731&quot;:0}"> </span></strong></p>
<p><span data-contrast="auto">Determinación del Turno: Se calcula el orden de actuación comparando la variable velocidad de todos los combatientes activos.  </span><span data-ccp-props="{}"> </span></p>
<p><span data-contrast="auto">Acciones por Turno: El jugador selecciona en la interfaz una acción: atacar, defender, usar habilidad (descontando manaActual) o consumir un Item del inventario.  </span><span data-ccp-props="{}"> </span></p>
<p><span data-contrast="auto">Fin del Combate y Experiencia: Si la vida de todos los enemigos llega a 0, la party recibe experiencia. Si la variable experiencia supera el límite, se ejecuta el método subirDeNivel(), el cual incrementa de forma permanente las estadísticas del personaje.  </span><span data-ccp-props="{}"> </span></p>
